# SAE_5
SAE 5 project aiming to develop a mobile image recognition app capable of identifying vehicles from pictures.

The project combines **mobile development** with **machine learning**, using a custom-trained image classification model to recognize different car models.

## 🛠️ Technologies

- **Python**
- **TensorFlow / Keras**
- **MobileNetV3**
- **Transfer Learning**
- Mobile development *(add your framework here)*

## 🎯 Objectives

- Build and train a vehicle image classification model
- Integrate the trained model into a mobile application
- Allow users to identify a vehicle from a picture
- Evaluate and improve recognition accuracy
